# mqtt_bridge

This is an enhancement and extension to the project 
[https://github.com/ika-rwth-aachen/mqtt_client](https://github.com/ika-rwth-aachen/mqtt_client)
providing docker deployment context.

## Prerequisites
`Docker` and `GNU Make` installed

## Usage
To run the bridge use the provided make target:
```bash
make up
```

To stop the services run:
```bash 
make down
```
